# FoodHive

A responsive food ordering and checkout UI built with React.

## Features

- Restaurant and food menu display
- Add items to cart
- Increase/decrease item quantity
- Remove items from cart
- Dynamic order totals and charges
- Checkout and payment flow
- Delivery address and instructions
- Responsive desktop and mobile UI

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Redux Toolkit
- React Router
- Lucide React

## Getting Started

### 1. Clone the repository

```
git clone {url}
cd {project_path}

2. Install dependencies
npm install
3. Start the development server
npm run dev

The application will be available at:

http://localhost:3000
```
